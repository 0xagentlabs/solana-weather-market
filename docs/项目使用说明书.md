# 项目使用说明书

## 项目简介与信任边界

Rain or Shine 是仅运行于 Solana Devnet 的上海指定日期降雨预测市场。参与者使用无价值的 Devnet SOL 进入 YES/NO 池，赢家按份额领取。数据来自 Open-Meteo 上海坐标（31.2304, 121.4737）的 `daily.precipitation_sum`；授权预言机钱包负责把观测值签名发布上链。因此它是可审计的中心化预言机 Demo，不应被描述为完全去中心化，也不可用于真实资金。

## 架构与目录

- `program/`：Rust + Pinocchio 链上程序；不依赖 Anchor runtime。
- `app/`：Next.js App Router、TypeScript、Wallet Adapter 与显式 ABI 客户端。
- `app/app/api/weather/route.ts`：Open-Meteo 服务端代理，固定上海坐标。
- `docs/ABI.md`：指令、账户、PDA 与错误码的权威说明。

## 环境、安装与启动

需要 Rust、Solana CLI 4.x、cargo-build-sbf、Node 22+ 与 pnpm 11+。

```bash
cargo test
cargo build-sbf
cd app
cp .env.example .env.local
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:3000`。钱包切换至 Devnet；RPC 必须是 `https://api.devnet.solana.com`。连接 Phantom 或 Solflare 后粘贴 Market PDA 即可读取状态并下注。

## 地址与操作

- Program ID：`HHkVyAqfGWvZrWuNqw1BwLqnr22Hbiwxp1exdoAxpzug`
- Program Explorer：https://explorer.solana.com/address/HHkVyAqfGWvZrWuNqw1BwLqnr22Hbiwxp1exdoAxpzug?cluster=devnet
- Market/Vault/Position PDA 见 `docs/ABI.md`，前端实现位于 `app/lib/abi.ts`。

创建市场时指定未来目标日、提前至少一天的封盘时间、观测时间、雨量阈值和 oracle 公钥。PlaceBet 选择 YES/NO 并填写 SOL；同一钱包在同一市场只能选择一边，可多次加仓。CloseMarket 仅 authority 可提前封盘。SettleMarket 仅 oracle 可签名，并从 `/api/weather?date=YYYY-MM-DD` 获取 Open-Meteo 数据。结算后赢家 Claim；oracle 长时间不工作时，在观测时间 48h 后使用 Refund。

交易签名可通过 `solana confirm <SIGNATURE> -u devnet` 确认，账户可通过 `solana account <ADDRESS> -u devnet` 查询。指令参数及账户顺序必须严格遵循 ABI；本项目没有 Anchor IDL。

## 测试、构建与部署

```bash
cargo fmt --all -- --check
cargo clippy --workspace -- -D warnings
cargo test
cargo build-sbf
cd app && pnpm test && pnpm build
solana program deploy target/deploy/weather_market.so --program-id keys/weather-market-keypair.json --url devnet
```

Program keypair 在 `keys/` 且被 `.gitignore` 排除，绝不能提交或展示私钥。部署前必须检查 `solana config get`、`solana address`、`solana balance` 并确认不是 mainnet-beta。

## 常见错误与安全注意事项

- `InvalidPda`：客户端 seed、target timestamp 或 Program ID 不匹配。
- `MarketClosed`：已封盘或超过 close_ts。
- `Unauthorized`：当前钱包不是 authority/oracle。
- `InvalidTime`：观测时间不在 ±24h 或数据超过 48h 新鲜度。
- `RefundUnavailable`：市场已结算，或尚未超过退款保护期。
- 交易失败先确认钱包、RPC 都在 Devnet，且有足够测试 SOL 支付租金与费用。

不要复用生产密钥、不要向 Demo 转入主网资产。预言机私钥只能由运行环境管理；链上只保存公钥。
